A push-optimal Sokoban solver in a single main.ts: it splits each level into its rooms (a box pushed into the hallway can never come back, so the rooms are independent), then solves every room with a breadth-first search over pushes — dead-square and frozen-block pruning, a transposition table, and a deterministic work budget instead of a clock — so every box lands on a goal in the fewest pushes there are.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=output node main.ts
```
